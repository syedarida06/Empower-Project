# Empower - Social Impact Platform

## Overview
Empower is a responsive social impact platform built to make it easier for women, children, and families to find support, submit requests, and stay informed about the progress of their cases.

Instead of limiting the website to awareness and information, Empower introduces a structured support journey — from discovering relevant resources and requesting assistance to receiving a Case ID and tracking the request.

## Features
Responsive navigation bar  
Home page  
About page  
Initiatives and resources section  
User registration and login  
Personalized user dashboard  
Support request submission  
Support categories and priority selection  
Unique Case ID generation  
Case progress tracking  
Request history  
Contact and support section  
Clean and user-friendly interface  

## Technologies Used
HTML  
CSS  
JavaScript  
Browser Local Storage  

## Real-World Problem Solved
People seeking social support often face scattered information, unclear processes, and limited visibility after reaching out for help.

Empower addresses this gap by bringing **support discovery, request submission, case identification, and case tracking into one organized digital experience**, making the support process easier to understand and follow.

## Project Status
Currently under development.

This project was developed to apply frontend development skills to a real-world social problem and demonstrate how a simple digital system can improve the accessibility, organization, and visibility of social support services.
