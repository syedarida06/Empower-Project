# Empower - Social Impact Platform

Empower is a responsive website designed to showcase initiatives, spread awareness, and provide an organized digital platform for social impact activities.

## Features
- Responsive navigation bar
- Home page
- Contact page
- About page
- Initiatives section
- Login page
- Clean and user-friendly interface

# Technologies Used
- HTML
- CSS
- JavaScript

# Project Status
Currently under development.
